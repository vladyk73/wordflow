WORD FLOW PWA — завантаження на GitHub Pages

Завантажте в корінь репозиторію всі файли та папку:
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

Важливо:
- не перейменовуйте папку icons;
- після Commit зачекайте 1–3 хвилини;
- відкрийте сайт і зробіть Ctrl+F5;
- PWA не встановлюється при відкритті index.html як локального file://;
- на Android у Chrome: меню ⋮ → Встановити застосунок / Додати на головний екран;
- на iPhone у Safari: Поділитися → На початковий екран.

Версія service worker: wordflow-shell-v1.
При майбутніх змінах сайту треба підвищувати номер кешу, наприклад v2.
