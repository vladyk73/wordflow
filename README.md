# WordFlow Dictionary

**WordFlow** — персональний англо-український словник і тренажер слів із темами, прогресом, хмарною синхронізацією та інтервальним повторенням.

Проєкт зроблений як легкий односторінковий вебзастосунок, який можна відкрити у браузері або встановити на телефон як PWA.

## Можливості

- Англо-український словник із транскрипцією.
- Слова, фрази, фразові дієслова та ідіоми.
- Кілька тем для одного запису.
- Статуси: **Нове / Вчу / Вивчено**.
- Пошук англійською та українською, включно з нечітким пошуком із дрібними помилками.
- Фільтри за темами, типом запису та статусом.
- Алфавітна навігація по словнику.
- Додавання, редагування та видалення власних слів.
- Безпечне видалення тем:
  - видалити лише тему;
  - видалити тему разом зі словами, які належать тільки їй.
- Undo після видалення слова, теми або об’єднання дублікатів.
- Масовий імпорт із попереднім переглядом.
- Перевірка масового імпорту на:
  - нові записи;
  - точні дублікати;
  - можливі дублікати з однаковим English, але іншим перекладом.
- Окремий пошук уже існуючих дублікатів у словнику.
- Безпечне об’єднання дублікатів зі збереженням тем, транскрипції та SRS-прогресу.
- Експорт і резервна копія даних.
- Прогрес по темах.
- Тренажер у напрямках:
  - English → Українська;
  - Українська → English;
  - змішаний режим.
- Оцінки карток:
  - **Не знаю**;
  - **Ще вчу**;
  - **Знаю**.
- Інтервальне повторення (SRS).
- Окремий список **«Повторення на сьогодні»**.
- Кілька англійських відповідників для одного українського перекладу.
- Озвучення англійських слів через браузер.
- Кнопка 🔊 для повторного прослуховування вимови.
- Google-вхід і синхронізація через Firebase.
- Локальне збереження даних.
- Темний режим.
- Адаптивна мобільна версія.
- PWA: можна встановити на телефон як окремий застосунок.
- Кнопка швидкого повернення нагору.
- Прихована пасхалка з любовними фразами ❤️.

## Поточна версія

**v11.8.2**

Service Worker cache: `wordflow-shell-v27`.

## Як працює SRS

WordFlow використовує власну спрощену систему інтервального повторення, натхненну SM-2.

Розклад створюється після першої оцінки слова у тренажері. Старі записи без SRS-історії не вважаються простроченими автоматично.

### Не знаю

Слово планується до повторення **не раніше ніж через 3 дні**.

Якщо слово вже вивчалося, збільшується кількість забувань (`lapses`).

### Ще вчу

Початкові інтервали приблизно:

- 5 днів;
- 7 днів;
- далі інтервал поступово збільшується.

### Знаю

Початкові інтервали приблизно:

- 7 днів;
- 14 днів;
- 30 днів;
- далі ще рідше.

Максимальний інтервал може доходити до 180 днів.

Після оцінки **«Не знаю»** слово більше не підсовується повторно через кілька карток у цій самій сесії.

## Кілька англійських відповідників

Якщо в словнику є кілька англійських записів з однаковим українським перекладом, WordFlow може показати їх разом у режимі **Українська → English**.

Наприклад:

```text
кількість
→ amount of
→ number of
→ quantity of
```

Поточне слово картки при цьому виділяється окремо.

## Озвучення

Для англійських слів використовується браузерний `SpeechSynthesis`.

У режимі:

- **English → Українська** — англійське слово можна озвучити одразу;
- **Українська → English** — озвучення доступне після відкриття відповіді, щоб не підказувати слово.

Якість і голос залежать від браузера та встановлених системних голосів на пристрої.

## Дублікати

WordFlow має два рівні перевірки дублікатів.

### Під час масового імпорту

Записи визначаються як:

- **Новий запис**;
- **Точний дубль** — збігаються English і український переклад;
- **Можливий дубль** — English однаковий, але український переклад відрізняється.

Для можливого дубля можна:

- об’єднати з існуючим записом;
- створити окремий запис;
- пропустити.

Це дозволяє уникати випадкових повторів, але не заважає зберігати різні значення одного англійського слова.

### Перевірка вже існуючого словника

Кнопка **«🔍 Знайти дублікати»** перевіряє вже додані записи з однаковим English.

WordFlow показує їх групами та дозволяє вручну вирішити, які записи потрібно об’єднати, а які залишити окремими.

Під час об’єднання зберігаються:

- теми;
- транскрипція;
- українські переклади;
- SRS-прогрес.

## Розгортання на GitHub Pages

Завантаж у корінь репозиторію:

```text
index.html
manifest.json
service-worker.js
favicon.ico
icons/
README.md
LICENSE
```

Після публікації відкрий сайт через HTTPS.

GitHub Pages може оновлювати сайт не миттєво. Статус розгортання можна перевірити у вкладці **Actions** або в розділі **Deployments** репозиторію.

При оновленні файлів PWA потрібно змінювати версію кешу в `service-worker.js`, наприклад:

```js
const CACHE_NAME = 'wordflow-shell-v28';
```

Це допомагає браузеру та встановленій PWA-версії отримати свіжі файли замість старого кешу.

## Встановлення як застосунку

Після відкриття опублікованого сайту браузер може запропонувати встановити WordFlow як PWA.

Після встановлення WordFlow запускається з іконки на головному екрані та відкривається як окремий застосунок.

## Дані та синхронізація

WordFlow підтримує:

- локальне збереження;
- окремий локальний кеш для користувача;
- Google Authentication;
- синхронізацію словника через Firestore;
- резервний JSON-експорт та імпорт;
- збереження SRS-прогресу під час синхронізації та редагування слів.

Дані користувачів у Firestore мають бути захищені правилами доступу, які дозволяють користувачу читати й змінювати лише власні документи.

## PWA

До проєкту входять:

- `manifest.json`;
- Service Worker;
- favicon;
- іконки 192×192 та 512×512;
- кешування оболонки застосунку;
- підтримка встановлення на мобільний пристрій.

Google-вхід та синхронізація через Firebase потребують мережі, навіть якщо сама оболонка застосунку вже доступна з кешу.

## Розробка

WordFlow розвивається поступово як персональний навчальний застосунок для накопичення словника, повторення слів і контролю прогресу.

Основний принцип проєкту — не втрачати дані користувача під час оновлень, синхронізації, редагування або об’єднання записів.
