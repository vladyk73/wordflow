# WordFlow Dictionary

**WordFlow** — персональний англо-український словник і тренажер слів із темами, прогресом, хмарною синхронізацією та інтервальним повторенням.

Проєкт зроблений як легкий односторінковий вебзастосунок, який можна відкрити у браузері або встановити на телефон як PWA.

## Можливості

- Англо-український словник із транскрипцією.
- Слова, фрази, фразові дієслова та ідіоми.
- Кілька тем для одного запису.
- Статуси: **Нове / Вчу / Вивчено**.
- Пошук англійською та українською, включно з нечітким пошуком із дрібними помилками.
- Фільтри за темами, типом запису та статусом.
- Алфавітна навігація по словнику.
- Додавання, редагування та видалення власних слів.
- Undo після видалення слова або теми.
- Масовий імпорт із попереднім переглядом.
- Експорт і резервна копія даних.
- Прогрес по темах.
- Тренажер у напрямках:
  - English → Українська
  - Українська → English
  - змішаний режим
- Оцінки карток:
  - **Не знаю**
  - **Ще вчу**
  - **Знаю**
- Інтервальне повторення (SRS).
- Окремий список **«Повторення на сьогодні»**.
- Повтор слова через 5–8 карток у поточній сесії після оцінки **«Не знаю»**.
- Адаптивні інтервали повторення до 180 днів.
- Google-вхід і синхронізація через Firebase.
- Локальне збереження даних.
- Адаптивна мобільна версія.
- PWA: можна встановити на телефон як окремий застосунок.
- Кнопка швидкого повернення нагору.
- Прихована пасхалка з любовними фразами ❤️.

## Поточна версія

**v9.1**

Основні останні зміни:

- додано SRS та повторення на сьогодні;
- старі слова не потрапляють автоматично у величезну чергу повторення;
- SRS активується після першої оцінки слова;
- покращено мобільний вигляд тренажера;
- компактніший SRS-блок;
- кнопки оцінки краще виглядають на вузьких екранах;
- перед SRS-сесією можна обрати напрямок тренування.

Service Worker cache: `wordflow-shell-v7`.

## Як працює SRS

WordFlow використовує власну спрощену систему інтервального повторення, натхненну SM-2.

### Не знаю

- слово повертається приблизно через 5–8 карток у поточній сесії;
- наступне планове повторення — наступного дня;
- для слів, які вже вчилися, збільшується кількість забувань (`lapses`).

### Ще вчу

Інтервал збільшується обережніше, щоб складні слова повторювалися частіше.

### Знаю

Інтервал збільшується швидше. Максимальний інтервал — 180 днів.

Старі записи без SRS-історії не вважаються простроченими автоматично. Розклад створюється після першої оцінки слова в тренажері.

## Структура проєкту

```text
/
├── index.html
├── manifest.json
├── service-worker.js
├── README.md
├── LICENSE
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

Увесь основний інтерфейс і логіка застосунку знаходяться в `index.html`.

- GitHub Pages

Збірка не потребує Node.js, npm або окремого backend-сервера для розміщення статичної частини.

## Розгортання на GitHub Pages

Завантаж у корінь репозиторію:

```text
index.html
manifest.json
service-worker.js
icons/
README.md
LICENSE
```

Після публікації відкрий сайт через HTTPS.

При оновленні файлів PWA бажано також змінювати версію кешу в `service-worker.js`, наприклад:

```js
const CACHE_NAME = 'wordflow-shell-v8';
```

Це допомагає встановленій версії застосунку отримати свіжі файли.

## Встановлення як застосунку

Після відкриття опублікованого сайту браузер може запропонувати встановити WordFlow як PWA.

Після встановлення WordFlow запускається з іконки на головному екрані та відкривається як окремий застосунок.

## Дані та синхронізація

WordFlow підтримує:

- локальне збереження;
- окремий локальний кеш для користувача;
- Google Authentication;
- синхронізацію словника через Firestore;
- резервний JSON-експорт та імпорт.

Дані користувачів у Firestore мають бути захищені правилами доступу, які дозволяють користувачу читати й змінювати лише власні документи.

## PWA

До проєкту входять:

- `manifest.json`;
- Service Worker;
- іконки 192×192 та 512×512;
- кешування оболонки застосунку;
- підтримка встановлення на мобільний пристрій.

Хмарні функції, Google-вхід та синхронізація потребують мережі, навіть якщо сама оболонка застосунку вже доступна з кешу.

## Розробка

WordFlow розвивається поступово як персональний навчальний застосунок.

Найближчий запланований великий UI-крок — **нічний режим**.
