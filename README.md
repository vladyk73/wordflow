# WordFlow Dictionary

WordFlow Dictionary — персональний словник англійських слів і фраз із темами, статусами вивчення, фільтрами та режимом повторення.

Проєкт зроблений як простий односторінковий сайт без окремого сервера. Дані користувача зберігаються у Firebase і синхронізуються між пристроями після входу через Google.

## Можливості

- особистий словник англійських слів і фраз;
- переклад українською;
- IPA-транскрипція;
- типи записів:
  - слово;
  - фраза;
  - фразове дієслово;
  - ідіома;
- кілька тем для одного запису;
- статуси:
  - Нове;
  - Вчу;
  - Вивчено;
- пошук;
- фільтрація за типом, статусом і темами;
- сортування A → Z, Z → A та за датою додавання;
- додавання, редагування та видалення записів;
- створення та видалення тем;
- масове додавання слів;
- імпорт TXT / CSV / JSON;
- резервна копія через JSON;
- режим повторення;
- напрямки повторення:
  - English → Українська;
  - Українська → English;
  - Змішаний;
- Google-вхід;
- синхронізація між телефоном і комп'ютером через Firebase;
- підтримка роботи з кешем Firestore;
- адаптація під мобільні екрани.

## Як працюють дані

Після першого входу через Google користувач отримує стартовий набір слів.

Після цього словник стає особистим:

- слова можна видаляти;
- можна додавати власні;
- можна змінювати переклади, транскрипції та теми;
- видалені стартові слова не повинні автоматично повертатися;
- прогрес синхронізується між пристроями.

Кожен Google-акаунт має окремі дані у Firestore.

## Firebase

Проєкт використовує:

- Firebase Authentication — вхід через Google;
- Cloud Firestore — зберігання словника, тем і прогресу;
- Firestore local cache — для кращої роботи при нестабільному інтернеті.

Firebase Web API key у клієнтському коді не є паролем. Доступ до даних обмежується через Firebase Authentication і Firestore Security Rules.

Приклад правил:

```js
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}
```

## GitHub Pages

Сайт можна розмістити безкоштовно через GitHub Pages.

Головний файл проєкту повинен називатися:

```text
index.html
```

Після публікації потрібно додати GitHub Pages домен у:

```text
Firebase Authentication
→ Settings
→ Authorized domains
```

Наприклад:

```text
username.github.io
```

## Структура даних Firestore

Спрощено:

```text
users
└── USER_UID
    ├── words
    │   ├── notes_001
    │   ├── notes_002
    │   └── ...
    └── settings
        └── dictionary
```

Кожне слово зберігається окремим документом.

## Резервні копії

У сайті є:

- Експорт JSON;
- Імпорт JSON.

Експорт рекомендується іноді використовувати як додаткову резервну копію словника.

## Призначення

WordFlow створений як персональний навчальний словник, а не як класичний тестовий застосунок.

Основна ідея:

> накопичувати власну лексику, сортувати її за темами, бачити прогрес і повторювати саме ті слова, які потрібні зараз.
